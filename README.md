# Game Art Portfolio

A responsive portfolio website for a 2D/3D game artist and Unity developer.

## Upload to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Customize

Open `index.html` and replace:
- `your.email@example.com`
- ArtStation / LinkedIn / GitHub `#` links
- Project titles/descriptions
- "Anti-Hero" with your preferred portfolio name

To add real images, replace the placeholder `.thumb` areas with `<img>` elements or background images.
